# portfolio-personal-research

AI Adoption and Collective Bargaining in Europe

This project asks a simple question: do countries with stronger collective bargaining coverage adopt AI more slowly or more quickly?

I compare the share of firms using AI (Eurostat) with the share of workers covered by collective agreements (OECD/ICTWSS) across European countries.

Methods: data cleaning and merging with pandas, descriptive statistics, scatter plot, correlation and a simple regression.

Status: version 1 (one year, one indicator). Next steps: firm size, sector, panel data and robustness checks in R.
